# Интерпретируемость SHAP и диагностика смещения (пункт 2.3)

**Дата запуска:** 2026-10-03  
**Область анализа:** текущие сохранённые модели. Для этой проверки модели не переобучались.

## Цель

Анализ охватывает две задачи пункта 2.3: локальные объяснения отдельных вердиктов и глобальную диагностику возможной зависимости от артефактов длины.

## Данные и методика

Для глобального сравнения используется отложенный файл `datasets_test/xss_dataset.csv` (13 226 строк). Детерминированная выборка из 128 строк стратифицирована по `source` и `label` (по 64 строки на каждую представленную группу).

| Модель | Метод атрибуции | Размер выборки | Параметры |
|---|---|---:|---|
| CatBoost | Нативный CatBoost TreeSHAP | 128 | Среднее абсолютное SHAP; текстовый и инженерные признаки сохранены |
| Random Forest | TreeSHAP | 128 | Среднее абсолютное SHAP |
| Logistic Regression | LinearSHAP | 128 | Перед атрибуцией применён scaler, использованный при обучении |
| SVM | KernelSHAP | 128 | Фоновая выборка 32 строки; 64 возмущения на одно объяснение |

Признаки ранжируются по среднему абсолютному SHAP. Эвристика помечает модель, если не менее трёх из пяти верхних признаков входят в группу длины/энтропии: `length`, `url_length`, `html_length`, `js_max_length`, `js_string_max_length`, `entropy`, `word_count`, `url_special_characters`, `special_char_ratio`.

В API также реализованы объяснения отдельных запросов: TreeSHAP для CatBoost/RF, LinearSHAP для LR, KernelSHAP для SVM и Integrated Gradients по embedding-токенам для LSTM/Transformer. Оценка ансамбля остаётся средним вероятностей выбранных моделей; API указывает модель, для которой построено объяснение. Предсказание Transformer и его Integrated Gradients были успешно проверены на локальном checkpoint и установленных зависимостях.

## Ограничения и интерпретация

В отложенном файле источник полностью совпадает с классом: все 6 613 строк `payloadbox` размечены как XSS, а все 6 613 строк `generated` — как benign. Поэтому такая выборка не позволяет исключить source-артефакты или подтвердить обобщение на независимо собранные источники. Признак `text` входит в число наиболее влиятельных у CatBoost, но сам по себе не является интерпретируемым семантическим признаком.

Результат эвристики означает только, что в этой выборке признаки длины/энтропии не заняли три или более позиции в top-5. Это не доказывает отсутствие смещения или причинность решений моделей.

Файл `unified_dataset.csv` новее сохранённых файлов моделей. Результаты описывают текущие checkpoint, а не модели, переобученные на последней версии датасета. После выбора итоговых обученных моделей анализ следует повторить.

## Воспроизведение

Из корня репозитория:

```powershell
.\.venv\Scripts\python -m xssdetector.generate_shap_report
```

Ранжирования и флаги диагностики сохраняются в `xssdetector/results/global_shap_heldout.json`.
